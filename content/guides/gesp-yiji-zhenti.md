## GESP 一级真题：零基础考生的第一站

### GESP 一级考试简介

GESP 一级是整个 GESP 认证体系的 **起点级别**，面向刚刚开始学习 C++ 编程的学生。

| 项目 | 详情 |
|------|------|
| **级别** | GESP C++ 一级（Level 1） |
| **考试时长** | 120 分钟（9:30-11:30） |
| **考试费用** | 300 元/人 |
| **题型** | 单选题 + 判断题（通常约 25-27 题） |
| **总分** | 100 分 |
| **特点** | 不含编程大题，全部为客观题 |

### 一级考纲核心要点

#### 必须掌握的知识点

**1. 基本数据类型**

```cpp
int a = 10;        // 整数
double b = 3.14;   // 小数（浮点数）
char c = 'A';      // 字符
bool d = true;     // 布尔值（true/false）
string s = "hello"; // 字符串
```

**2. 变量的定义与赋值**

- 变量命名规则（字母/数字/下划线，不能数字开头）
- 变量先定义后使用
- 赋值运算符 `=`

**3. 算术运算符**

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `+` | 加法 | `3 + 5` → `8` |
| `-` | 减法 | `10 - 4` → `6` |
| `*` | 乘法 | `3 * 7` → `21` |
| `/` | 除法（整数除法截断） | `7 / 2` → `3` |
| `%` | 取模（取余数） | `7 % 2` → `1` |

⚠️ **GESP 一级易错点**：整数除法的截断特性！`7 / 2 = 3` 不是 `3.5`。

**4. 输入输出**

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;      // 输入
    cout << n;     // 输出
    cout << "n = " << n << endl;  // 输出带文字
    return 0;
}
```

**5. 简单的顺序结构程序**

一级的程序都是 **从上到下顺序执行**，不涉及分支和循环（那些是二级的内容）。

### 一级真题中的高频题型

#### 题型 1：运行结果推断

**示例**：
```cpp
int a = 5;
int b = 3;
int c = a + b * 2;
cout << c;
```
问：输出结果是？

> 答案：`11`（先乘法 `3*2=6`，再加法 `5+6=11`）

#### 题型 2：数据类型与取值范围

考查 `int`、`double`、`char`、`bool` 类型的特点和区别。

#### 题型 3：表达式求值

考查运算符优先级、整数除法、取模运算等。

#### 题型 4：概念辨析

考查变量命名规则、注释写法、`#include` 的作用等基础概念。

### 答题技巧

1. **不会的题先跳过**：一级全是选择题/判断题，不会的标记下来最后回头想
2. **注意「输出什么」vs「值是多少」**：有些题问变量的值，有些问程序的输出，别混淆
3. **整数除法看到就警觉**：看到 `/` 就想是不是整数除法
4. **时间充裕**：120 分钟做 25 道题，平均每道题近 5 分钟，不用慌
