## GESP 是什么考试？

**GESP**，全称 **CCF 编程能力等级认证**（Grade Examination of Software Programming），是由 **中国计算机学会（CCF）** 发起并主办的面向青少年的编程能力等级考试。

简单来说，GESP 就是一张能证明你（或你的孩子）编程能力达到什么水平的「官方成绩单」。

### GESP 的核心信息速览

| 项目 | 内容 |
|------|------|
| **全称** | CCF 编程能力等级认证（Grade Examination of Software Programming） |
| **主办方** | 中国计算机学会（CCF） |
| **启动时间** | 2022 年 9 月 |
| **认证语言** | C++、Python、图形化编程（Scratch） |
| **级别设置** | C++ / Python：1–8 级；图形化：1–4 级 |
| **考试频率** | 每年 4 次（3 月、6 月、9 月、12 月） |
| **考试方式** | 全国各考点统一上机考试 |
| **官方网址** | https://gesp.ccf.org.cn |

### GESP 与其他编程考试的区别

市面上少儿编程考级不少，GESP 的核心差异化优势在于 **「CCF 官方血统」**：

- **与 NOI / CSP-J/S 同源**：GESP 和全国青少年信息学奥林匹克竞赛（NOI）、CSP-J/S 非专业级软件能力认证由同一个主办方（CCF）出品，命题团队来自清华大学、北京大学、北京航空航天大学等高校专家。
- **高等级衔接竞赛**：GESP C++ 8 级成绩 ≥ 80 分可免 CSP-S（提高组）第一轮；7 级 ≥ 80 分或 8 级 ≥ 60 分可免 CSP-J（入门组）第一轮。这是其他编程考级无法提供的「直通车」。
- **覆盖全学段**：从一级（适合零基础入门）到八级（接近竞赛水平），循序渐进，不同阶段的学生都能找到合适的级别。

### GESP 各级别考察内容概览

| 级别 | 主要内容 | 适合人群 |
|------|----------|----------|
| **1-2 级** | 变量、数据类型、输入输出、分支结构、循环基础 | 零基础或学完入门课程 |
| **3-4 级** | 数组、字符串、函数、递归、简单排序与查找 | 系统学完 C++ 基础语法 |
| **5-6 级** | 栈、队列、链表、树的基础、排序算法、贪心 | 有一定算法基础 |
| **7-8 级** | 图论、动态规划、高级数据结构、复杂算法综合 | 竞赛方向，目标 CSP-J/S |
